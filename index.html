Cadence

A clock that walks through a timed program.

A program is a JSON file: a title, and a list of entries that each say which week and weekday they belong to rather than what date they fall on.

Program format ↓

The parts

A program is built from these two, and they run on their own.

One step

A sequence of them

For a language model

Read this section and answer with one JSON object and nothing else. It is the whole contract: anything not described here is rejected.

title
a name for the program.
entries
the sessions, in the order they should be done.
week
which week the entry belongs to, counting from 1.
day
1 is Monday, 7 is Sunday. Never a date — Cadence works the dates out itself.
label
the short line the list shows. Keep it under about 25 characters and make each one recognisable at a glance.
sequence
what actually runs: title and blocks. Each block has repetitions and steps; each step has a label, a durationSeconds (fractions allowed), and optionally startFrequency and endFrequency in hertz, which beep at the two ends of the step.
milestone
a fixed point, such as a race or a review: "milestone": true with a date of the form YYYY-MM-DD and a title. Only a milestone may carry a date. Its sequence is optional — leave it out for something that is only reached and recorded rather than performed.

The first milestone anchors the whole program backwards from its date, so the plan lands where the event really is. Sessions slide when you finish late; a milestone never moves.

{
  "title": "Eight-week strength",
  "entries": [
    {
      "week": 1,
      "day": 1,
      "label": "Push · 20s x2",
      "sequence": {
        "title": "Week 1 — Push",
        "blocks": [
          {
            "repetitions": 2,
            "steps": [
              {
                "label": "Push-up",
                "durationSeconds": 20,
                "startFrequency": 440,
                "endFrequency": 880
              },
              { "label": "Rest", "durationSeconds": 25 }
            ]
          }
        ]
      }
    },
    {
      "week": 9,
      "day": 6,
      "milestone": true,
      "date": "2026-11-07",
      "title": "Retest"
    }
  ]
}
